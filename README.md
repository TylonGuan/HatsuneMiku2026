#### [Hatsune Miku 2026 Contest](https://magicalmirai.com/2026/procon/index_en.html)

Developing a web application using TextAlive App APIs! Build an interactive application and other visual effects to accompany the song of the [Magicial Mirai Music Contest](piapro.jp/pages/official_collabo/magical2026_musiccontest/result)!

In this project, I planned to focus this application on the Grand Prize winner song **"こたえて feat. 初音ミク" by imie** ("Answer Me feat. Hatsune Miku" by imie )

I wish to demonstrate modern use of instrustry standard technologies when building this static application. Such as using React, Weblab, and Three.js.

As an added challange, I also wish to support a Machine Translation English subtitles.
